# Whisper tiny model files

- Model: [Xenova/whisper-tiny](https://huggingface.co/Xenova/whisper-tiny)
- License: Apache-2.0
- Runtime: Transformers.js 3.8.1 / ONNX Runtime Web
- Included variants: quantized ONNX encoder and merged decoder

These files are served by the website itself so browser transcription does not depend on a separate model-host download. They are open-source model weights; this project does not call a paid transcription or inference API.
